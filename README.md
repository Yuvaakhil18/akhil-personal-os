# Akhil Personal OS

An interactive personal portfolio operating system for C. Yuva Akhil.

## Run locally

This is a dependency-free frontend. Serve the repository root with any static server, for example:

```bash
python -m http.server 4173
```

Then open `http://localhost:4173`.

## Customize

Edit `content/owner-profile.js` for identity, projects, links, and approved claims. Visual styles live in `styles.css`; app behavior lives in `app.js`.
